# IXD2026 — 資料導演台 (Data Director Console)

用 **KORG nanoKONTROL2 / nanoPAD2** 兩台 MIDI 控制器，即時「演奏」一顆**化為海洋的 3D 星球**——透明球殼裡的療癒深海，內含水母、魚群、鯨豚、海龜與海洋垃圾，並有一片逐漸轉化成文字與數字的海。參數可 MIDI Learn 綁定、可錄製回放、可分享、可錄影下載。資料主題可延伸至台灣**政府開放資料**（[Twinkle Hub](https://hub.twinkleai.tw/zh-TW)）。

> 核心命題：把抽象的多維資料，變成一台可以用雙手演奏的資料樂器。

---

## 快速開始

```bash
npm install
npm run dev
```

用**桌面版 Chrome / Edge** 開啟 http://localhost:5173，按「連線 MIDI」允許權限。

> Web MIDI 需要 Chrome / Edge + localhost 或 HTTPS。Safari 支援較不穩；內建瀏覽器沙盒會擋 MIDI 權限——實體裝置請用你自己的 Chrome。

## 主要功能

| 功能 | 說明 |
|---|---|
| 3D 海洋球 | Three.js / R3F；透明球殼 + 程序化波浪 + 海洋生物 + 流動文字；**滑鼠拖曳 / 旋鈕改變旋轉** |
| 參數面板 | 分組滑桿，每個參數可 **MIDI Learn** 綁定 CC |
| 錄製 / 播放 | 把整段旋鈕演出錄下並回放；**soft-takeover** 播放中抓旋鈕平順接管、不跳值 |
| 分享 | 產生帶參數的網址（`?s=…`），複製即分享目前視覺狀態 |
| 分享星球 | 擷取此刻的海合成分享卡（帶目前資料列）→ 手機系統分享 / 桌機下載 PNG。**實景（AR）時連相機拍到的真實背景一起輸出**：以 `object-fit: cover` 的幾何把相機畫面對位到畫布、套用與畫面相同的背景模糊 / 清澈濾鏡，再疊上透明的 WebGL 畫布（舊版 Safari 沒有 `ctx.filter` 時以縮放近似模糊）；「錄影」同理逐幀合成 |
| 多人合奏 | 按「多人」秀 QR，手機掃碼變遙控器（PeerJS WebRTC，短 ID → QR 小而好掃）；每支手機分到「聲部」（海 / 生態 / 氛圍 / 自由）、滑桿每秒跟主畫面同步；**手機感測器**：啟用後傾斜=洋流方向、搖晃=浪湧（走同一條 wire 協定）。全部走同一條 `input()` 路徑（可錄製、可 soft-takeover）。host 與訊號伺服器斷線會用同一 ID 自動重連、被銷毀則換號重建 |
| 真實資料 | 水庫水位 % **直接等於海水高度**（滿庫=滿球，>97% 液體從球外緣溢流、球底積水痕）；石門 / 德基 / 曾文附 24h 進流量、**花蓮外海附 CWA 潮汐**時間序列，可「▶ 播放資料」讓球隨真實資料起伏（**倍速 ×0.5–×4、循環**，畫布上方 HUD 顯示資料時刻與數值）；另有「**揚塵 · 雲林縣**」「**月亮 · 花蓮**」兩個海況，全部資料集見下方〈資料集 → 畫面〉 |
| 銀河 × 河川 | 背景帶狀銀河，濃度由**水利署即時河川水位**（5 站 / 警戒比）驅動——水豐則銀河更亮 |
| 鳥群 / 魚群 × 調查資料 | 球外線稿鳥群數 =「鳥群數量」參數（0..1 → 0..5 群）；魚群同理走「魚群數量」。資料卡顯示該流域**逐月物種數長條圖**（斜線＝內插、點長條預覽月份、標示現在），並給資料建議值，你可以「**套用資料**」、開「**連動**」（換海況 / 換月份時自動更新），或直接拖曳滑桿「**獨立控制**」（手動調會自動脫鉤，參數列的「資料」標籤消失）。每個流域另有**調查年表**可「▶ 播放」：每一步＝一個調查年度，數量隨當年物種數變化。⚠ 資料誠實聲明：各流域僅部分月份 / 年度有調查（每月只涵蓋 1–3 個年度，近似單一年份快照，非氣候平均），只收紀錄數達門檻的月份，缺月以相鄰月份**環狀內插**並標註「內插」 |
| 月亮 × 潮汐 | 潮汐海況時背景出現月亮：**盈虧＝當日月齡（由 CWA 農曆日期推得，與潮汐資料同源）**、位置＝月中天時刻與當下時刻決定的天空弧線（新月正午 / 上弦傍晚 / 滿月午夜中天）。資料播放 24h 潮位時月亮真的東升西落，HUD 同步顯示乾/滿潮標記、農曆、潮差、月相。另有獨立海況「**月亮 · 花蓮**」：以 CWA A-B0063-001 的月出 / 中天 / 月沒時刻、月出月沒**方位角**與中天**仰角**把月亮放在真實的方位與高度（閒置＝今天 × 現在時刻內插；「▶ 播放月出月沒」每一步＝一天，月亮每晚 21:00 的位置與盈虧逐日推進，中天越高海水越高＝示意） |
| 資料看板 · 輸出顯示資料 | 畫布左上「資料看板」列出目前海況背後的真實資料與映射（水庫 / 潮汐 / 揚塵 / 氣象 / 鳥 / 魚 / 河川 / 測站，手機預設關）；**OUT 監看**在套用海況時輸出「資料 …」列、資料播放**每一步**輸出「DATA …」行；「分享星球」圖片也帶資料列；匯出 LOG 一併包含 |
| 畫面資訊面板控制 | 畫布上的資訊面板分三組、各自可關：**資料看板** / **播放與參數提示**（資料播放進度、參數數值、待接管旋鈕提示、AR 調整鈕、聲音提示）/ **掃碼 QR 與統計**（演出模式）。頂部「**資訊**」鈕或鍵盤 **`I`** 一鍵全部隱藏 / 顯示（再按一次還原原本的組合）；看板右上 **×**；資料卡「畫面顯示」三個勾選分別開關；偏好存 localStorage。網址覆寫 `?hud=0`（看板+提示）/ `?board=0` / `?qr=0`（給展場、錄影用，不會蓋掉使用者偏好）。隱藏的面板直接卸載（不空跑動畫迴圈） |
| 背景模糊 / 清澈 | 「VIEW」的兩支滑桿（可 MIDI Learn / 錄製 / 手機遙控）：**只作用背景**（星空 / 銀河 / 流星 / 月亮 / 測站星座，AR 時＝相機畫面），球體與生物保持清晰。實作：背景放 layer 1 → 先畫背景 → 複製畫面 → Kawase 雙濾波（多層降 / 升採樣，近似高斯、稀疏星點不會重影）→ 蓋回（含清澈度）→ 再疊前景；預設值零額外成本、GPU 不支援時自動降級 |

| 物理垃圾 | cannon-es 剛體：瓶 / 袋浮在水面、互相碰撞、被洋流推、被**淨化波推開** |

| Marker 快照 | nanoKONTROL2 Track ◀▶＝上/下一場景；Marker Set＝存當下狀態為快照（最多 8 組）、Marker ◀▶ 巡回 |

| 場景配色 | 每個場景一組色相（湛藍 / 紫粉 / 碧綠 / 濁綠 / 青藍），水線、粒子、大氣、霧一起轉調；「海色色相」也是可演奏參數 |
| Gamepad / 指北針 | 手把左桿=洋流方向、右桿=自轉與海水高度、A/B/X/Y=召喚；手機轉身（羅盤 >8°）=洋流轉向 |

| 手機 RWD | 窄螢幕自動改為上下堆疊 + 觸控互動 |
| 本機儲存 | localStorage / sessionStorage 記住參數、綁定、尺寸、錄製、日誌 |

## 控制對應（nanoKONTROL2 出廠預設）

**6 推桿 (Slider 1–6, CC0–5)**

| 推桿 | 效果 |
|---|---|
| 1 | 海水高度 |
| 2 | 洋流速度 |
| 3 | 水母數量 |
| 4 | 魚群數量 |
| 5 | 垃圾數量 |
| 6 | 海水清澈程度 |

**2 旋鈕 (Knob 1–2, CC16–17)**：旋轉海洋球 / 生物游動速度。

**4 按鈕 (Button 1–4, Solo CC32–35)**：鯨魚出現 / 海豚出現 / 海龜出現 / 清除垃圾。

**走帶鍵**：● 錄製開始/結束、▶ 播放/停止、■ 停止、Cycle 清除錄製——演出全程不碰滑鼠。

**LED 回饋**（nanoKONTROL2 需以 KORG Kontrol Editor 設 LED Mode = External）：錄製中 ● 閃、播放中 ▶ 亮、待播放 ■ 亮、Learn 模式 Cycle 閃、soft-takeover 待接管時該軌 R 鍵閃、觸發鍵按下亮 0.3 秒。

**藍牙 MIDI（Web Bluetooth）**：「藍牙 MIDI」鈕直接以 GATT 連 BLE-MIDI 控制器 / 鍵盤（不必先在系統配對），與 USB 共用同一條 `routeMidi` 路徑，Learn / 錄製 / soft-takeover 通用。支援 Chrome / Edge（桌面、Android）；**iPad / iPhone 的 Safari（與其他 iOS 瀏覽器）沒有 Web Bluetooth，也沒有 Web MIDI**——那些裝置請用「多人」掃 QR 當遙控器（WebRTC，不需藍牙）。

**nanoPAD2 X-Y 觸控板**：X（Pitch Bend）→ 洋流向 X（攪動浪的方向）；Y 預設不綁（點「洋流向 Y」→ 滑觸控板即 Learn）。

**nanoPAD2 打擊墊：16 效果 × 4 bank（=64 墊）**：`note % 16` 選效果、`note ÷ 16` 選強度檔位（弱 / 中 / 強 / 爆，對應 nanoPAD2 Scene 或音高區段），velocity＝力度。效果表：水母脈衝 / 浪湧 / 漣漪 / 氣泡 / 亮星 / 海豚 / 鯨魚 / 海龜 / **淨化波** / 垃圾投放 / 洋流轉向 / 閃光 / 魚群衝刺 / 漣漪三連 / 星雨 / 大浪+氣泡。虛擬控制器有相同的 16 墊 + bank 切換。

**手機觸控／感測**：左右拖曳=旋轉（放手有慣性）、上下滑=海水高度、兩指縮放=遠近、點擊=亮星爆發、**長按 0.5 秒=魚群聚集到手指**、**傾斜手機=水面保持水平**、**搖晃=攪動海水**（iOS 首次觸碰會請求感測權限）。可「加入主畫面」以 PWA 全螢幕離線使用。

> **生態連動**：垃圾增加 → 海水混濁、生物減少、**魚群主動繞開垃圾**、點綴音轉小調；清除垃圾 → **淨化波**擴散、生物回歸、聲音回到大調。背景另有 4 分鐘一輪的極慢晝夜。
> 若你的裝置 CC 不同：**點參數名稱 → 轉旋鈕**即重綁（Learn），或按「依序對應旋鈕」；`shift+點` 解綁。按鈕也可用畫面上的動作鈕（滑鼠 / 觸控）。綁定存 localStorage。

## 錄製 / 播放

1. `● 錄製` → 動旋鈕 / 拖球體 / 拉滑桿演出 → `■ 停止錄製`
2. `▶ 播放` 重現整段；`⟲ 清除` 重錄
3. **soft-takeover**：播放時抓實體旋鈕，需先讓實體值「經過」畫面當下值才接管，避免跳值；手動拉滑桿 / 拖球體則即時接管
4. 錄製自動存 localStorage，重開仍可播放

## 分享

按 `分享` → 複製一條帶目前參數的網址（`?s=<base64>`）。對方開啟即載入你的視覺狀態。

## 錄影

按 `錄影` → 擷取星球 10 秒 → 自動下載 `ixd2026-globe.mp4`（瀏覽器不支援 MP4 時退回 `.webm`）。

## 匯出 LOG

按 `匯出LOG` → 下載 `ixd2026-log.txt`（帶時間戳的 IN/OUT 訊息），供除錯 MIDI / 事件流。

| **月出月沒時刻 A-B0063-001**（CWA，花蓮縣） | 月亮的方位 / 高度（閒置＝今日 × 現在時刻；播放＝逐日） | 逐日（滾動 180 天） |

**資料限制（誠實聲明）**
- **揚塵**：IoW 端點只給「最新一筆」，歷史由 CI 每 3 小時追加一筆（以來源時戳去重、保留最近 120 筆 ≈ 15 天），剛部署時只有 1 筆，資料卡顯示「累積中」。目前 PM10 感測器一律回傳哨兵值 4999.4（另有氣溫 1956.96℃ 的離譜值），腳本判為無效 → `null`：此時海況以預設 PM10 = 40 μg/m³ 示意（看板會標「PM10 無效」），歷史播放改以**風速**驅動洋流與海水混濁。來源也可能凍結（時戳前進、數值不變）。
- **測站**：只有站點目錄（沒有流量時間序列）；TWD97 二度分帶座標換算成相對座標，僅用於背景星座。
- **月出月沒**：API 預設只回一小段，要帶 `timeFrom` / `timeTo` 才回其他範圍（單次最多 180 天；目前公開 2025-01-01 → 2027-12-31）。CI 取「今日前 2 日起 180 天」的滾動視窗，抓取失敗則保留舊窗口；畫面以 `from / to` 判斷是否涵蓋今日，不涵蓋時閒置的月亮退回天文公式。方位角以正北 0°、順時針；每個陰曆月各有一天沒有月出或月沒。
- **魚 / 鳥調查**：多數流域只有 4–5 個有效月份 / 年度，缺月以相鄰月份環狀內插（標註「內插」）；每月只涵蓋 1–3 個年度，近似單一年份快照，非氣候平均。花蓮溪鳥類 2017–2019 的數量欄位全空（年表的隻次為空）。物種名已正規化（字面 "NULL"、別名順序）。
- 水利署 opendata 在**並行**請求時約 1/4 會回錯置 / 空白 / 截斷的內容，腳本一律依序抓並重試；GitHub runner 連 WRA / CWA 的成功率尚未在 Actions 實測，任何資料集失敗都只會保留舊資料、不影響其他資料集。

**測試**：`node --test src/lib/series.test.mjs scripts/gov/gov.test.mjs`（播放序列、輸出文字、各資料集的解析與哨兵值處理；含對真實 `ocean.json` 的 smoke test）。
